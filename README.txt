CONTACT BOOK - ANDROID STUDIO PROJECT

Technology:
- Kotlin
- Jetpack Compose
- Room Database
- MVVM
- Repository pattern
- Kotlin Coroutines and Flow

How to open:
1. Extract ContactBook.zip.
2. Open Android Studio.
3. Choose File > Open.
4. Select the extracted ContactBook folder (the folder containing settings.gradle.kts).
5. Allow Gradle Sync to complete.
6. Use JDK 17 for Gradle.
7. Run the app on an emulator or Android phone.

Features:
- Add contacts with name, phone and email.
- View contacts in a LazyColumn.
- Delete contacts.
- Persist contacts locally with Room.
- Observe database changes through Flow.

Note:
The project uses Android Gradle Plugin 8.13.2 and compileSdk 36.
Install Android SDK Platform 36 in SDK Manager if Android Studio asks for it.
This ZIP contains the Android Studio project source and Gradle configuration;
Android Studio will download dependencies during the first Gradle sync.
